# Dirty Thoughts Fashion — Design Vault

This directory is the source of truth for DTF creative work.

## Rules
1. Never replace an approved design with AI-generated substitute art.
2. Product mockups are outputs, not source artwork.
3. Original slogans, artwork specifications, and visual references live here.
4. New revisions get a new version; old approved designs stay archived.
5. Storefront/Printify automation must read from this vault or an explicitly approved successor.

## Structure
- catalog-v1.json — original 40-product slogan/category catalog
- design-system.md — approved visual rules
- visual-references.md — pointers to existing repo reference images
- references/ — screenshots/contact sheets/reference material
- source/ — editable/source artwork
- exports/ — production PNG/SVG exports
- mockups/ — generated Printify/storefront mockups
- archive/ — superseded versions
